# Voice sample script (about 2 minutes)

**How to record**
- Quiet room, no fan or music. Phone or laptop mic about a hand's width from your mouth.
- Talk the way you would explain your work to a friend: relaxed, natural pace. Don't perform.
- Pause for a breath between paragraphs. If you stumble, just repeat the sentence; I'll clean it up.
- Save it as `ME/voice-sample.m4a` (Voice Memos on Mac or iPhone works great; AirDrop it over).
